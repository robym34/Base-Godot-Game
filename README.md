
# Base Godot Game

A template for any Godot game, contains the plugins that would probably be the most useful for any developer.


## Usage

Just click the "Use this template" button in the top right, and create a new repository.

Then you can clone the new repository and edit it however you want!


## Plugins included

- [Godot Git](https://store.godotengine.org/asset/markus-steen/godot-git/), for easy access to Version Control tools.
- [Kanban Tasks](https://store.godotengine.org/asset/holonproduction/kanban-tasks/), for planning and keeping track of a project's state.
- [YARD](https://store.godotengine.org/asset/elliotfontaine/yard-yet-another-resource-database/), an easy to use resource database.
- [GodotGAS](https://store.godotengine.org/asset/indiegamedad/godotgas/), to manage stats and abilities in your game without incurring into any coupling issues.
- [Ruzta](https://store.godotengine.org/asset/seremtitus/ruzta/), an extended version of the GDScript language.
